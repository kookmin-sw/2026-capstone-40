# 팀 소개

Capstone 2026 Team 40은 Reverse IP lookup 기반 domain tracking monitor를 개발했습니다.

## 인원

- 박윤재
- 박진우
- 송예찬

## 역할

| 영역 | 담당 내용 |
| --- | --- |
| Capture pipeline | traffic input, `.pcap` 처리, retry delay, filtering boundary |
| Domain intelligence | reverse IP lookup, source 선택, verification, cache 동작 |
| Risk analysis | threshold, scoring 동작, alert severity, decision label |
| Dashboard | Rust route, Askama template, chart, analyst page |
| Documentation | GitHub Pages site, Markdown content, demo script, usage guide |
