# Traffic-to-Domain Risk Monitor

Capstone 2026 Team 40은 원시 네트워크 관찰 정보를 도메인 단위의 보안 맥락으로 변환하는 Rust 기반 모니터링 파이프라인을 구축했습니다.

이 시스템은 캡처된 트래픽에서 시작해 관찰된 IP 주소를 가능한 도메인으로 역조회하고, 결과에 위험도 점수를 부여한 뒤 더 깊은 프로브가 필요한 대상만 올립니다. 결과적으로 검토해야 할 원시 패킷은 줄이고, 설명 가능한 도메인 수준 알림은 늘리는 간결한 로컬 조사 콘솔을 제공합니다.

## 프로젝트 소개

- 트래픽 캡처는 실시간 인터페이스와 `.pcap` 파일을 지원합니다.
- 역방향 IP 조회는 관찰된 IP를 후보 도메인으로 변환합니다.
- 위험도 점수화는 도메인을 `skip`, `watch`, `probe` 결정으로 분류합니다.
- 능동 프로브는 고위험 도메인에 대해 HTML, 리다이렉트 정보, 스크린샷, asset, 관련 메타데이터를 수집합니다.
- Rust 대시보드는 상태, 알림, 도메인, 프로브 결과를 표시합니다.

## 제품 구성

애플리케이션은 다섯 가지 주요 화면을 제공합니다:

- 전체 도메인 수, 활성 알림, 캡처된 IP, 프로브 실행 수를 보여주는 대시보드 지표.
- 심각도, 알림 유형, 상세 정보, 타임스탬프, 확인 상태를 보여주는 알림 화면.
- 위험도 점수, 결정, IP, 마지막 관찰 시각, 알림 수를 보여주는 도메인 화면.
- IP 이력, 알림, 위험 신호, 스냅샷을 보여주는 도메인 상세 페이지.
- 소스 선택과 선택적 검증을 포함한 역방향 IP 조회 프로브 흐름.

## 필요성

보안 분류 작업은 IP 주소에서 시작되는 경우가 많지만, 유의미한 결정을 내리려면 도메인 맥락이 필요합니다. 이 프로젝트는 수동 캡처, 역조회, 점수화, 선택적 프로브를 하나의 로컬 흐름으로 결합해 그 간격을 줄입니다.
