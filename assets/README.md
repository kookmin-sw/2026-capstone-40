# Assets

이미지, 영상, 영상 썸네일 같은 GitHub Pages 정적 자산을 이 디렉터리에 둡니다.

`cargo run --release`를 실행하면 이 디렉터리의 파일이 `site/assets/`로 복사됩니다.

권장 용도:

- 대시보드 스크린샷.
- 도메인 상세 화면 스크린샷.
- 프로브 결과 스크린샷.
- 소개 영상 썸네일.
- 짧은 `.mp4` 데모 영상.

영상 권장 사항:

- 브라우저 호환성을 위해 H.264/AAC 기반 `.mp4`를 사용합니다.
- 큰 영상은 저장소에 직접 넣지 말고 외부 호스팅 링크를 사용하는 편이 좋습니다.
- 영상 썸네일은 `demo-poster.jpg`처럼 별도 이미지로 둡니다.
