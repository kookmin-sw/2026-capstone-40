# Capstone 2026 Pages Branch

This branch contains the GitHub Pages site for Capstone 2026 Team 40.

The application source code is intentionally not kept on this branch. The site is generated by a small Rust static-site generator in `src/main.rs`, using Markdown content from `book/`, and deployed by the GitHub Actions workflow in `.github/workflows/pages.yml`.

## Local Preview

Build the static site:

```bash
cargo run --release
```

The generated site is written to:

```text
site/
```

For GitHub Pages deployment, push to the `page` branch and make sure the repository Pages source is configured to use GitHub Actions.
